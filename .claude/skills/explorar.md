# Explorar — generar opciones antes de decidir

Divergente: amplía el espacio de posibilidades antes de convergir. Úsalo ANTES de /pensar.

## Cuándo usarlo
Cuando el usuario no sabe qué opciones existen, o cuando la pregunta es abierta.
Trigger automático cuando el usuario pregunta "qué podríamos hacer", "qué opciones hay", "cómo podríamos mejorar X".

## Qué hacer

1. Generar 4-6 opciones genuinamente distintas (no variaciones del mismo enfoque)
2. Para cada opción: una frase de qué es + una frase del trade-off principal
3. Señalar cuál parece más prometedora y por qué (sin extenderse)

## Formato de salida

```
### Opciones para [tema]

1. **[Nombre corto]** — [qué es]. Trade-off: [coste vs beneficio].
2. **[Nombre corto]** — [qué es]. Trade-off: [coste vs beneficio].
...

*La más prometedora parece [X] porque [razón en una frase].*
```

## Notas
- Las opciones deben ser realmente distintas, no matices de la misma idea
- No implementar ni profundizar — solo mapear el espacio
- Si el usuario quiere profundizar en una, pasar a /pensar
