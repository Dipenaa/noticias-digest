# Context

Visión del proyecto, propuesta de valor y restricciones conocidas.

**Qué es:** Digest personal de noticias en español. Descarga ~51 feeds RSS, analiza cada artículo con Claude (sesgo, crítica, sentimiento, asombro) y genera un HTML interactivo con síntesis cruzada entre medios.

**Público:** Adrian Pedolin — uso personal.

**Restricciones clave:**
- Coste máximo: ~10-15 céntimos/día
- Render plan gratuito: la app hiberna si no hay tráfico
- Claude Haiku para análisis masivo, Sonnet solo para síntesis
