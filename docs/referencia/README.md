# Referencia

Material externo que informa el diseño y producto: inspiraciones visuales, benchmarks, competidores.

## Referencias de diseño consultadas
- **Axios** — minimalismo extremo, mucho espacio, sin decoración
- **The Atlantic** — serif editorial, acento único, blanco y negro
- **Rest of World** — alto contraste, tres typefaces con roles distintos
- **Morning Brew** — bloques visuales, muy escaneable
- **The Pudding** — data visual, ilustrativo
- **Apple Newsroom** — paleta limpia, jerarquía tipográfica clara
